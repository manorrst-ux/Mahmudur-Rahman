Admin Panel সেটআপ বাকি

নিরাপদ লগইন ও ডেটাবেসের জন্য Supabase সেটআপ করতে হবে।

কোনো পাসওয়ার্ড HTML-এ রাখা হয়নি। Supabase Auth ও database policy দিয়ে অ্যাডমিন অনুমতি যাচাই হবে।

১. Supabase খুলুন ↗

২. SQL Editor-এ supabase-schema.sql ফাইলের SQL চালান।

৩. Authentication → Users থেকে নিজের ইমেইল দিয়ে user তৈরি করে SQL দিয়ে admin করুন।

৪. Project URL ও anon/publishable key supabase-config.js ফাইলে বসান। Secret/service_role key দেবেন না।

অ্যাডমিন লগইন

শুধু অনুমোদিত অ্যাডমিন প্রবেশ করতে পারবেন।

অ্যাকাউন্ট Supabase Dashboard → Authentication → Users থেকে তৈরি করুন।
